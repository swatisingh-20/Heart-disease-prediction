❤️ Heart Disease Prediction

A Machine Learning based web application that predicts the risk of heart disease based on selected patient health parameters.

📌 About the Project

This project uses a K-Nearest Neighbors (KNN) machine learning model to predict heart disease risk.

The trained model and preprocessing scaler are saved using Joblib and integrated into an interactive Streamlit web application.

🛠️ Technologies Used

- Python
- Pandas
- Scikit-learn
- KNN
- StandardScaler
- Joblib
- Streamlit

⚙️ How It Works

1. User enters patient health parameters.
2. The input data is converted into the required format.
3. The saved scaler preprocesses the input.
4. The trained KNN model makes the prediction.
5. The application displays the predicted risk.
